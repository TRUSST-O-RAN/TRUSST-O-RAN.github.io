# TRUSST-O-RAN documentation

Project description, all four Thrust 1 task specifications, the shared virtual
testbed, validation evidence, and Task 1 development status.

Live site: https://trusst-o-ran.github.io/

Built with Sphinx and the Read the Docs theme, hosted on GitHub Pages.

```text
python -m pip install -r requirements.txt
python -m sphinx -W --keep-going -b html docs _build/html
```

The complete portable lab is included in [testbed/virtual](testbed/virtual/README.md).
